# Day 7 – Abstraction, Interface, Composition & Mini Projects

Today’s learning focused on advanced Object-Oriented Programming (OOP) concepts
in Python. I practiced abstraction, interface-like behavior, composition, and
applied these concepts by building small real-world projects.

## Concepts Covered
- Abstraction using base classes
- Interface-style design using method definitions
- Method implementation in child classes
- Multiple inheritance with abstraction and interface
- Composition (HAS-A relationship)
- Real-world design thinking using OOP
- Encapsulation using protected variables

## Practice Examples
- Payment system using abstraction (UPI, Card, Cash)
- Shape area calculation using abstract methods
- Course and Exam system using abstraction + interface
- Composition example using Student and Address
- Car and Engine example (HAS-A relationship)

## Mini Projects

### 1. Bank Account Management System
- Implemented BankAccount as a base class
- Created SavingsAccount and CurrentAccount using inheritance
- Used abstraction for interest calculation
- Applied encapsulation for balance handling
- Built a controller class (BankApp) to manage operations

### 2. Employee Payroll System (OOP Design)
- Designed Employee base class
- Implemented Full-Time and Part-Time employees
- Salary handled using encapsulation
- Payroll system acts as a controller (HAS-A relationship)
- Demonstrates abstraction and polymorphism

## Learning Outcome
This day helped me understand how complex real-world systems
can be modeled using OOP principles like abstraction,
composition, and encapsulation in Python.
