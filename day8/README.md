# Day 8 – Regex, Python Modules & File Handling

Today’s learning focused on using Python’s built-in modules and regular
expressions to solve real-world problems. I also practiced generating data,
processing it, and saving results into files.

## Topics Covered
- Regular Expressions (regex)
  - Email extraction
  - Digit extraction from text
  - Strong password validation pattern
- Python built-in modules
  - random (number generation)
  - math (rounding values)
  - os (directory and file handling)
  - collections.Counter (frequency counting)
- File handling (writing reports to files)

## Practice Tasks
- Generate random numbers using Python
- Identify even and odd numbers
- Calculate and round average values
- Count frequency of numbers
- Create directories using `os`
- Save processed results into a text file

## Mini Task
- Automatically generate a report file containing:
  - Generated numbers
  - Even and odd numbers
  - Rounded average
  - Frequency of each number

## Learning Outcome
This day helped me understand how Python can be used to automate small tasks
by combining regex, modules, and file handling. It improved my confidence
in working with real data and saving outputs programmatically.
