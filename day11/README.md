FinTrack Pro

FinTrack Pro is a command-line based personal finance management system built using Python and SQLAlchemy ORM with SQLite as the database.
It helps users track expenses, organize them by categories, manage monthly budgets, and monitor spending patterns efficiently.

The project demonstrates practical usage of database relationships, CRUD operations, and raw SQL queries alongside ORM-based queries.

Features

Category Management

Add and organize expense categories

Expense Tracking

Add, update, delete, and search expenses by date

Link expenses to categories using foreign keys

Category-wise Expense Report

Generate summarized reports using SQL aggregation

Monthly Budget Management

Set monthly spending limits

Get alerts when expenses exceed the budget

Relational Database Design

One-to-many relationships between categories and expenses

Structured schema using SQLAlchemy ORM

Tech Stack

Python

SQLAlchemy (ORM + Raw SQL)

SQLite

Command Line Interface (CLI)

Purpose of the Project

This project was built to:

Strengthen understanding of ORM concepts

Practice database relationships and queries

Apply real-world finance tracking logic

Build a clean, modular CLI-based Python application
